Introduction

Base URL: http://localhost:8000

Bienvenido a la documentación de la API de Vibora Padel Store.

Esta API permite que el sitio comercial se comunique con el backend de la tienda, ofreciendo acceso al catálogo de productos de pádel y la posibilidad de generar pedidos.

Los endpoints de catálogo son públicos. La creación de pedidos no requiere autenticación: se realiza como invitado, registrando los datos de contacto y envío.

Recursos disponibles

  • Catálogo: listado y detalle de productos, categorías y marcas.
  • Tienda: creación de pedidos con datos del cliente, dirección e items.

Todas las respuestas se devuelven en formato JSON.

Authenticating requests

This API is not authenticated.

Catálogo

Endpoints públicos para explorar el catálogo de la tienda.

Listar productos

Devuelve los productos activos con paginación. Permite filtrar por categoría, marca y búsqueda.

Example request:
curl --request GET \
    --get "http://localhost:8000/api/products?category=paletas&brand=bullpadel&search=pala" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json"
const url = new URL(
    "http://localhost:8000/api/products"
);

const params = {
    "category": "paletas",
    "brand": "bullpadel",
    "search": "pala",
};
Object.keys(params)
    .forEach(key => url.searchParams.append(key, params[key]));

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};


fetch(url, {
    method: "GET",
    headers,
}).then(response => response.json());

Crear pedido

Crea un pedido desde la tienda con los datos del invitado, dirección e items. Si el email ya existe, reutiliza la cuenta. El pedido nace en estado "pendiente".

Example request:
curl --request POST \
    "http://localhost:8000/api/orders" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"customer\": {
        \"name\": \"Juan Pérez\",
        \"email\": \"juan@mail.com\",
        \"phone\": \"2804555123\",
        \"dni\": 35123456
    },
    \"address\": {
        \"street\": \"Av. Fontana 250\",
        \"city\": \"Trelew\",
        \"province\": \"Chubut\",
        \"postal_code\": \"9100\"
    },
    \"items\": [
        \"consequatur\"
    ]
}"

const url = new URL(
    "http://localhost:8000/api/orders"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "customer": {
        "name": "Juan Pérez",
        "email": "juan@mail.com",
        "phone": "2804555123",
        "dni": 35123456
    },
    "address": {
        "street": "Av. Fontana 250",
        "city": "Trelew",
        "province": "Chubut",
        "postal_code": "9100"
    },
    "items": [
        "consequatur"
    ]
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());
